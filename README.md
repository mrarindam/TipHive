# 🍯 TipHive

### 🚀 What is TipHive?
TipHive is the world's first **Bitcoin-native tipping platform** designed for creators. It allows fans and supporters to send tips directly to their favorite creators using Bitcoin-backed stablecoins (MUSD) on the Mezo L2 network.

### 🛠️ What does it do?
It provides a seamless, non-custodial way for creators to monetize their content. 
- Creators can set up a profile in seconds.
- Fans can tip instantly with near-zero transaction fees.
- Settlements are immediate—no more waiting for weeks to receive your earnings.

### ⏳ Why is it needed now?
The creator economy is booming, but traditional platforms (like YouTube or Twitch) take a massive cut (sometimes up to 30-50%) and often have slow payout cycles. With the rise of Bitcoin Layer 2s like Mezo, we finally have the technology to make micro-payments fast, cheap, and truly decentralized.

### 💡 What problem does it solve?
1. **High Fees:** Most platforms take a huge percentage of creator earnings. TipHive takes **0%**.
2. **Slow Payouts:** Traditional systems take days or weeks to clear funds. TipHive settles **instantly**.
3. **Censorship & Control:** Traditional payment processors can freeze accounts. TipHive is **non-custodial**, meaning you are always in control of your money.
4. **Volatility:** By using **MUSD**, creators get the security of Bitcoin with the stability of the US Dollar.

### 💻 Technical Stack
This project is built using modern, high-performance tools:
- **Frontend:** Next.js 16 with Tailwind CSS and Framer Motion for premium animations.
- **Backend:** Supabase for fast data management and user profiles.
- **Web3:** Wagmi, Viem, and RainbowKit for a smooth wallet connection experience.
- **Network:** Mezo L2 (Bitcoin Economic Layer).
- **Smart Contracts:** Solidity-based tipping contracts deployed on the Mezo Testnet.

## 🏁 Getting Started

1. **Install dependencies:** `npm install`
2. **Setup Env:** Copy `.env.example` to `.env.local` and add your keys.
3. **Run:** `npm run dev`

Visit [http://localhost:3000](http://localhost:3000) to see it live!
